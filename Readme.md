## 📖 專案主題與設計概念

本專案以日式幸運物——**「御結飯糰（御結び，Musubi）」**為核心主題，打造一個富有日系溫潤質感與生命力的祈願互動網頁。

### 1. 【 由來與底蘊 】
在日文裡，飯糰亦被稱作「御結び（Musubi）」。傳說日本古時人們將純淨白米捏塑成宛如神聖山嶽的三角形，祈求神明賜予大地豐收與平安庇佑。  
每一顆飯糰皆由手心一握一握成形，手掌交扣的溫度，象徵著人與人之間最真誠深厚的羈絆；每一顆飯糰不僅封存著大地的飽滿米香，更盛裝著製作者深深的溫暖祝福。

### 2. 【 三大象徵意涵 】
* 🌾 **豐收飽滿**：聚沙成塔、顆顆飽滿的米粒，象徵平日每一分努力的汗水與積累，終將化為豐碩的金黃收穫。
* ✨ **緣分相繫**：「結」字寓意相扣與牽絆，祈願連結身邊所有珍貴的善緣、溫暖的人事物與不期而遇的美好。
* 🍵 **安心守護**：純粹簡樸而溫熱踏實的存在，給予心靈最溫柔的撫慰，賦予隨時向前邁步的堅定勇氣。

## ⚡ 動態互動效果實作特色

本專案完全依據規格規範，實作了兼具療癒感與趣味性的互動效果：

### 1. 🍙 主角飯糰（緣結の飯糰）
* **滑鼠懸停（Hover）動態**：
  * **晃動光暈（Wiggle & Glow Pulse）**：游標靠近時，背後的金色光暈（`.glow-bg`）擴大並柔和呼吸脈動，飯糰帶有歡快的左右微搖擺（Wiggle Dance）。
  * **眼神與臉部視差追隨（Parallax Eye Tracking）**：飯糰的黑亮眼睛與五官會依據滑鼠座標輕微轉動注視，彷彿歪頭凝視著訪客。
  * **自然眨眼**：定時觸發自然眨眼微動態，增添生動生命力。
  * **氣泡小提示**：游標懸停時浮現「戳我一下沾沾福氣 ✨」小氣泡。
* **滑鼠點擊（Click）動態**：
  * **果凍擠壓彈跳（Squash & Stretch Bounce）**：點擊瞬間飯糰像麻糬般受壓扁平，隨後快速彈起並帶有自然的彈簧物理阻尼（Spring Physics）。
  * **笑瞇瞇開心表情（Happy Eyes）**：點擊瞬間眼睛轉化為開心的彎月瞇瞇笑眼（`^ ^`），雙頰泛起粉潤光芒。
  * **米粒與星芒粒子噴發（Particle Confetti Burst）**：以點擊位置為原點，真實模擬重力與阻力，瞬間向四面八方噴發出立體純白米粒、金色十字星芒（✦ / ★）與櫻花花瓣！
  * **浮現緣結祝福小金句（Floating Blessing Quotes）**：每次點擊，飯糰上方飄出一則溫暖幸運籤語並優雅淡出。
  * **福氣累加器**：每次互動皆會累加「今日已凝聚緣結福氣」份數。

### 2. 🎴 象徵意涵三卡片（🌾 豐收、✨ 緣分、🍵 守護）
* **3D 景深傾斜（3D Tilt & Lift）**：滑鼠在卡片上滑動時，卡片依游標位置產生即時的 3D 透視微傾角與柔和浮動陰影。
* **專屬和風主題光暈**：
  * 🌾 豐收：金黃稻穗光暈 + 稻穗隨風微擺動態。
  * ✨ 緣結：璀璨星芒光暈 + 星星旋轉脈衝。
  * 🍵 守護：清雅抹茶綠光暈 + 茶杯上方冒出升騰的裊裊熱氣。
* **點擊互動（Click Feedback）**：以點擊點為中心擴散和風水波紋漣漪（Ripple），並蓋上專屬朱紅「已結緣」御守印章！

### 3. 🎐 今日御神籤抽籤互動（Omikuji）
* 點擊「搖搖飯糰 · 領取今日御結籤」按鈕，飯糰會快速晃動祈願。
* 隨後翻開精緻的和風籤詩卡片（大吉、緣結吉、中吉等），揭示今日守護箴言、幸運御守物與幸運色，支援「再抽一次」與「收下好運」。

### 4. 🌸 環境氛圍與和風微音效
* **落櫻與金色微塵（Ambient Canvas）**：背景中輕盈飄落淡淡的櫻花瓣與金色微粒，營造靜謐和諧氛圍。
* **純 Web Audio API 物理合成音效**：無需下載額外 mp3 檔案，純瀏覽器即時合成清脆日式風鈴（Chime）與 Q 彈跳音，右上角附有「和風音效：開/關」切換開關。

## 🚀 運行與預覽方式

本專案使用標準純原生技術（HTML5 + Vanilla CSS3 + Vanilla JavaScript ES6+），無須安裝任何套件，即開即用：

1. **直接開啟**：在本機檔案總管中，直接雙擊 `index.html`，即可透過 Chrome、Edge、Firefox 等現代瀏覽器流暢開啟。
2. **本機伺服器**（可選）：亦可在專案目錄下透過終端機執行：
   ```bash
   python -m http.server 8080
   ```
   並於瀏覽器輸入 `http://localhost:8080/` 即可進行預覽。
